Recommendation for data collections

Species names - autocomplete list from background table (optional scientific or national names)

Using automatic species nam validation - auto_species_name column

Automatic observer name: login_name option

Timestamp field for observation data and time

obm_geometry field for GPS location

Using DWC naming scheme for field names

Form and field description is available in the mobile app


Occasional observation
......................
When we occasionally spot a potential target species that we think might be of interest if included 
in the database, this is known as incidental data recording. Such data are suitable for drawing occurrence 
maps. Incidental data cannot generally be used to produce species distribution maps, estimate population 
sizes or identify any trends.
Occasional forms can, of course, be used in accordance with specific protocols, which may extend the 
usefulness of the data collected in this way.
