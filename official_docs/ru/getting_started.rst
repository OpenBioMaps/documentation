Начало работы
*************

Выберите способ использования OpenBioMaps
=========================================
Чтобы создать проект OpenBioMaps, необходим доступ к серверу OpenBioMaps. Это
может быть ваш собственный или арендованный сервер либо уже обслуживаемый
кем-либо сервер, на котором размещаются проекты OpenBioMaps.

Присоединитесь к существующему серверу
--------------------------------------
Самый простой способ создать новый проект, иногда также называемый базой
данных, — воспользоваться существующим сервером OpenBioMaps. Просмотрите
список известных серверов, чтобы узнать, есть ли у вас доступ к одному из них.
Существуют специализированные публичные серверы, на которых размещается
множество различных баз данных.

Настройте собственный сервер
----------------------------
Если вам требуется больше ресурсов или вы хотите контролировать доступ ко
всему серверу, можно установить собственный сервер OpenBioMaps.

:doc:`Установка сервера OpenBioMaps <../server_install>`

Инструкции по установке с использованием Docker:

:doc:`Установка Docker <../docker>`


Создайте проект OpenBioMaps
===========================
На одном сервере OpenBioMaps может размещаться несколько проектов баз данных.
Перед созданием проекта необходим доступ к уже существующему проекту на
сервере. После получения доступа можно создать и настроить проект в
соответствии с требованиями вашего процесса сбора данных.

Необходимые шаги описаны в руководстве здесь: https://openbiomaps.org/documents/en/tutorials.html#new-project, и
здесь: https://openbiomaps.org/documents/en/new_project.html

Изучите модель данных наблюдений
================================
Прежде чем проектировать базу данных и формы сбора данных, полезно понять,
как OpenBioMaps представляет наблюдения за биоразнообразием.

:doc:`События наблюдений и отдельные наблюдения <../observation_events>`


Настройте данные
================
После создания проекта необходимо определить структуру данных и способ их
сбора.

OpenBioMaps позволяет создавать таблицы и поля базы данных, относящиеся к
конкретному проекту, и управлять ими. Структура базы данных должна
соответствовать информации, которую требуется регистрировать, а также связям
между различными типами данных.

Определите структуру базы данных
--------------------------------

Управление таблицами проекта и их столбцами осуществляется через
административный интерфейс. Зарегистрированные в нём таблицы и поля становятся
доступны в интерфейсах OpenBioMaps и могут использоваться для запросов и сбора
данных.

Рекомендуется добавлять описания таблиц и полей. Эти описания являются частью
метаданных проекта и помогают пользователям понять смысл данных и их
предполагаемое назначение.

:doc:`Административные настройки <../admin_settings>`

Создайте формы сбора данных
---------------------------

После определения структуры базы данных можно создавать формы загрузки для
ввода и сбора данных.

Форма загрузки определяет, какие поля доступны пользователям, какие из них
обязательны, каким образом вводятся значения и как осуществляется сбор
данных. Формы можно использовать для ввода данных через веб-интерфейс,
загрузки файлов и доступа через API.

:doc:`Управление формами загрузки <../upload_forms>`

Структура базы данных и формы сбора данных вместе определяют основной процесс
сбора данных в проекте OpenBioMaps.

* :doc:`Политика управления данными <../data_policy>`


Подключитесь к проекту
======================
Доступ к проектам OpenBioMaps можно получить через несколько интерфейсов и
инструментов в зависимости от способа сбора, управления или анализа данных.

Веб-интерфейс
-------------
Веб-интерфейс — основной инструмент управления проектом OpenBioMaps. Он
предоставляет инструменты для управления данными и пользователями,
конфигурации и администрирования.

:doc:`Интерфейс пользователя <../user_interface>`

:doc:`Административный интерфейс <../admin_settings>`

OpenBioMaps также предоставляет программные интерфейсы для внешних клиентских
приложений.

:doc:`API OpenBioMaps <../api>`


Интеграция с QGIS
-----------------
Плагин OpenBioMaps для QGIS предоставляет доступ к данным OpenBioMaps из QGIS.

`Плагин OpenBioMaps для QGIS <https://plugins.qgis.org/plugins/obm_connect/>`_

Пакет R
-------
Пакет ``obm`` для R предоставляет инструменты для доступа к данным OpenBioMaps
и работы с ними в R.

`obm в CRAN <https://cran.r-project.org/web/packages/obm/index.html>`_

Начните сбор данных и управление ими
====================================
Теперь проект OpenBioMaps готов к сбору данных.

В зависимости от вашего рабочего процесса данные можно вводить через
веб-интерфейс, загружать из файлов, собирать с помощью мобильных приложений
или передавать через API OpenBioMaps.

После добавления данных в систему их можно проверять, обрабатывать,
запрашивать, визуализировать, анализировать и предоставлять в общий доступ в
соответствии с процессом управления данными и правилами проекта.

Информацию о конкретных процессах сбора данных см. в разделе
:doc:`Примеры сбора данных в OpenBioMaps <../data_collection_examples>`.
