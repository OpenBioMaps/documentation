Прерванные импорты
------------------
При загрузке новых данных с помощью веб-форм или файлов можно сохранить
текущее состояние подготовленных данных.

При сохранении процесса загрузки данные и настройки сохраняются на сервере
OpenBioMaps. Сохранённое состояние можно восстановить, загрузив его
идентификатор.

Идентификаторы создаются автоматически. В рамках одного SESSION и одной
формы существует только один идентификатор. Поэтому инкрементное резервное
копирование не выполняется!

За сохранёнными импортами можно следить на странице профиля, перейдя по
ссылке **Interrupted imports**.


Предоставление данных в общий доступ
------------------------------------
Результаты запросов можно сохранять и предоставлять в общий доступ. В этом
случае пользователи, которым предоставлен запрос, видят не данные,
хранящиеся в базе данных, а их сохранённую версию. Состояние сохранённого
результата не изменяется: после создания оно становится полностью
независимым от базы данных. Любой пользователь, имеющий ссылку общего
доступа, может получить доступ к данным, сохранённым в запросе. Ссылка
общего доступа является постоянным идентификатором, который можно связать с
идентификатором DOI.


Закладки
--------
Запросы можно сохранять и повторять с помощью ссылок-закладок. Ссылки на
закладки нельзя предоставлять другим пользователям: они работают только
после входа в систему и только для создавшего их пользователя. В закладках
хранится сам запрос, а не его результат, поэтому изменения содержимого базы
данных повлияют на результаты, полученные с помощью закладки.


Ключи API
---------
Активные ключи API. Эта функция связана с аутентификацией. Она позволяет
отслеживать подключения и закрывать их вручную. В основном ею пользуются
разработчики.

Следующие элементы страницы необязательны и относятся к отдельным модулям,
разрешённым в проекте.

Настройки отдельных модулей
---------------------------
Некоторые модули могут предоставлять здесь интерфейсы управления. Например:
модуль создания пользователей PostgreSQL, модуль загрузки геометрии, модуль
запросов на скачивание и другие.


Управление пользовательскими геометриями
........................................
Эта функция доступна только в том случае, если её разрешает модуль
``shared_geoms``.

Пользовательские геометрии можно загружать или рисовать для последующих
действий. К таким действиям относятся выполнение пространственных запросов и
назначение геометрии загружаемым данным.

Управлять пользовательскими геометриями можно на странице профиля с помощью
двух ссылок: **Shared geometries** и **Own geometries**.

По ссылке **Own geometries** можно удалять геометрии или предоставлять к ним
общий доступ, переименовывать их и изменять параметры отображения. Доступны
следующие параметры отображения: **View in spatial selection list** и
**View in upload data - assign named spatial forms list**.

По ссылке **Shared geometries** можно переименовывать геометрии и изменять
параметры отображения. Удалять опубликованные геометрии нельзя!


Создание пользователя PostgreSQL
................................
Создание активной на один год учётной записи пользователя с доступом на
чтение таблиц данных проекта через клиентские программы SQL. Требуется для
использования QGIS!
